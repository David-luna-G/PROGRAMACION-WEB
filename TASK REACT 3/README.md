# Task React 3

Una versión sencilla del Task 3 con perfil, proyectos desplazables y un modal para compartir el perfil con contactos.

## Ejecutar

Abre una terminal en esta carpeta y ejecuta:

```bash
npm install
npx expo start
```

Escanea el código QR con Expo Go. Si no conecta, inicia con `npx expo start --tunnel`.
